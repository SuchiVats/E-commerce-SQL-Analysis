# E-commerce SQL Analysis

This repository contains a comprehensive analysis of e-commerce transactions using SQL. The goal is to analyze customer behavior, sales patterns, product combinations, and various trends within the e-commerce dataset. It covers several questions related to sales, customer profiling, revenue analysis, and product performance.


## Project Overview

The project utilizes SQL to analyze e-commerce transactional data from a database. The queries are designed to answer business questions such as:

- Identifying the number of orders based on value ranges (small, medium, large).
- Analyzing customer visit patterns and identifying the most frequent customers.
- Understanding the revenue breakdown by age, marital status, and income groups.
- Identifying the most frequently bought product combinations and the most valuable customers.
